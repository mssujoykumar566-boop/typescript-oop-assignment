# TypeScript & OOP Assignment

This repository contains the solutions for the TypeScript problem-solving and OOP assignment.

## Files

- `solutions.ts` — implementations of all eight required coding problems.
- `type-vs-interface.md` — blog post comparing type aliases and interfaces.
- `type-narrowing.md` — blog post explaining type narrowing with practical examples.

## Topics Covered

Optional parameters, union types, `typeof` narrowing, readonly tuples, generics, rest parameters, interfaces, `keyof`, OOP inheritance and access modifiers, and asynchronous Promises.

## Blog Posts

1. [Type Alias vs Interface in TypeScript](./type-vs-interface.md)
2. [Type Narrowing in TypeScript](./type-narrowing.md)

## Run

Install TypeScript in your project if it is not already installed, then compile the solution:

```bash
npx tsc solutions.ts --target ES2020 --module commonjs --strict
```

The assignment requires the repository to be public and the repository URL to be submitted.
